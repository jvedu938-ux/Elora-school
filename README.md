# 🏫 Elora International School

A modern and responsive school website built using **HTML, CSS, and JavaScript**.

## 🌐 Project Overview

Elora International School is a frontend school website designed to showcase school facilities, campus gallery, achievements, and admission information.

## ✨ Features

- 🏠 Modern Home Page
- 📚 About School Section
- 🏫 Smart Classrooms
- 🏆 Sports Facilities
- 💻 Computer Labs
- 🎨 Creativity & Activities
- 📊 Animated Statistics Counter
- 🖼️ Interactive Campus Gallery
- 🔍 Image Preview Modal
- 📖 Read More / Show Less
- 📱 Responsive Design
- 🎓 Admission Section
- 📞 Contact Information
- ✨ Scroll Header Effect

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- Responsive Design
